## 1.0.2 (2026-10-10)

本次更新新增 Root 模式，优化了 OOBE 体验与更新日志显示，并修复一处引导卡死问题。

### ✨ 新功能

- **Root 模式**：已 Root 的设备无需安装 Shizuku，即可在引导中直接完成授权
- **OOBE 添加磁贴后自动展开控制面板**：添加 exTile 磁贴成功后会尝试拉起控制中心，方便接着点「编辑」

### 🛠 优化

- 检查更新的更新日志改为 Markdown 渲染
- 「渐进模糊」仅在「模糊效果」开启时显示，并精简了副标题
- 跳过按钮倒计时从 5 秒缩短至 3 秒；打赏页与关于页文案更新
- 调试工具新增「Root 可用」与「特权通道模式」状态

### 🐛 问题修复

- 修复 OOBE 第 3 步「导入系统磁贴」在部分设备上卡死的问题

## 1.0.1 (2026-10-04)

这是一个维护性更新：修复了首次引导（OOBE）中的若干问题，磁贴目录优化。

### ✨ 新功能

- **从系统导入磁贴**：编辑页三点菜单新增「从系统导入磁贴」
- **添加磁贴更干净**：添加磁贴 Sheet 会自动隐藏无图标的磁贴
- **设备适配更精准**：工作台磁贴仅在小米系平板显示；散热风扇磁贴按机型代号门控
- **OOBE 更顺手**：跳过按钮改为始终显示，跳过倒计时缩短至 3 秒

### 🐛 问题修复

- OOBE 未完成时禁用 exTile 磁贴操作，避免引导完成前磁贴行为异常
- 导入预览卡片不再展示 edit 磁贴，且不再参与计数
- 修复首页卡片上边距过大、设置页调试工具入口图标

## 1.0.0 (2026-10-01)

exTile 的第一个正式版本：让 Android 控制中心，在简洁和效率之间找到「平衡」。

- **一键切换布局**：点击 exTile 磁贴，在「收起 / 展开」两套布局间瞬间切换
- **一页式磁贴编辑**：4 列网格拖拽排序，支持撤销上一步
- **丰富磁贴**：内置系统磁贴目录，支持自定义磁贴与其他应用提供的第三方磁贴，均可搜索
- **小米 / HyperOS 特化**：自动检测 MIUI / HyperOS，支持与系统「无字模式」「融合设备中心」联动
- **配置备份 / 恢复**：JSON 导出 / 导入 / 剪贴板，支持多备份管理与从系统一键导入
- **使用统计**：记录布局切换的展开 / 收起次数，主页实时查看
- **精致 UI**：HyperOS 设计语言，支持动态取色与深色模式，手机 / 平板 / 横屏自适应布局
