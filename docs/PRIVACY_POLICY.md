# exTile 隐私政策

> To English readers: This document is currently available only in Simplified Chinese, and the original text shall prevail.

生效日期：2026 年 9 月 30 日

## 1. 适用范围

本隐私政策适用于 exTile Android 应用（以下简称“本应用”）。本应用是一个用于管理 Android 快速设置面板磁贴的工具软件，由个人开发者 hrsthrt74 维护。

本应用的核心功能可以完全离线使用，不要求注册账号、登录或连接网络。本应用所有需要联网的功能均为可选且默认关闭，不开启不会影响核心功能。

本政策仅适用于本应用本身。通过应用内链接跳转的第三方网站或服务（例如 GitHub 发布页、开源项目主页等），其数据处理不受本政策约束，请参阅对应平台自身的隐私政策。

## 2. 本应用在本地处理的数据

为了实现功能，本应用可能在设备本地保存：

- 磁贴布局、磁贴显示方式和其他应用设置；
- 展开与收起磁贴的本地使用次数；
- 用户主动创建的配置备份文件；
- 隐私设置和匿名统计同意状态。

这些数据默认保存在设备本地。本应用不会因为读取或保存这些数据而自动上传配置、备份文件、应用列表或自定义磁贴名称。

应用内的“支持作者”功能仅展示微信收款码图片，供用户自愿打赏。打赏产生的数据由提供方处理（微信支付）。是否打赏不影响本应用的任何功能。

## 3. 可选的 Microsoft Clarity 匿名统计

本应用集成 Microsoft Clarity，用于在用户明确开启“允许匿名统计”后分析应用使用情况，帮助改进交互体验。该选项默认关闭，不同意不会影响本应用的核心功能。

在用户开启后，Clarity 可能处理以下信息：

- 页面交互行为，例如页面访问和点击行为；
- Android 版本、设备型号等设备基础信息；
- 本应用版本等应用基础信息；
- 本地展开、收起次数对应的统计标签。

本应用会尽量遮挡应用选择器、自定义磁贴名称和跳转目标等敏感界面内容，但无法承诺第三方 SDK 在所有情况下都能达到绝对匿名。Microsoft Clarity 对数据的处理还受其自身隐私政策约束。

用户可以随时在“设置 → 关于”中关闭匿名统计。根据当前 SDK 的能力，关闭后需要重启本应用才能完全停止数据收集。用户也可以通过系统设置来禁止本应用联网。

## 4. 权限与系统数据

本应用可能使用 `WRITE_SECURE_SETTINGS`、Shizuku 和 Android 系统接口来读取或修改系统磁贴配置。相关操作主要在设备本地完成，不会因为授权本身向开发者上传数据。

Shizuku 是独立的第三方软件，其行为受 Shizuku 自身项目说明和许可约束。

## 5. 可选的自动检查更新

本应用提供可选的“自动检查更新”功能，该选项默认关闭。未开启时，本应用不会为此功能发起任何网络请求。

用户开启后，本应用会在每次冷启动时（且已完成首次引导）向 GitHub Releases API 发起一次检查请求，地址为：

<https://api.github.com/repos/hrsthrt74/exTile/releases/latest>

关于该请求：

- 请求不携带任何用户数据或设备标识，仅包含标准 HTTP 头；
- 应用只会读取响应中的版本号、更新说明和发布页链接，用于与本机版本比较及展示；
- 未发现新版本或检查失败时，应用不会弹出任何提示；
- 发现新版本时，应用会弹窗提示，点击“前往查看”会跳转到 GitHub 发布页面；
- 本功能依赖 `INTERNET` 网络权限；
- 用户可以随时在“设置 → 关于 → 版本”或首次引导的数据与隐私页中关闭该功能，关闭后不再发起相关请求；
- 用户也可以在设置页手动触发检查，行为与上述自动检查相同。

## 6. 数据保留与删除

本地数据会保留到用户主动修改、删除应用数据或卸载本应用为止。用户可以通过 Android 系统设置清除本应用数据，也可以删除自己导出的备份文件。本地数据保存在本应用专属的存储空间内，受 Android 系统的沙箱隔离机制保护，但任何本地存储方式都无法承诺绝对安全，请自行妥善保管重要配置。

由 Microsoft Clarity 处理的数据，其保留和删除规则由 Microsoft 的相关政策决定。

## 7. 未成年人

本应用是面向一般用户的系统工具，不面向儿童设计，也不会故意收集未成年人的个人信息。如监护人对相关问题有疑问，可以通过第 9 节的联系方式与维护者联系。

## 8. 政策变更

当功能、数据处理方式或第三方服务发生变化时，本页面会更新生效日期。重大变化会尽量在应用内提供提示。
