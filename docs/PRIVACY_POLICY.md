# exTile 隐私政策

生效日期：2026 年 8 月 16 日

## 1. 适用范围

本隐私政策适用于 exTile Android 应用（以下简称“本应用”）。本应用是一个用于管理 Android 快速设置面板磁贴的工具软件，由个人开发者维护。

本应用的核心功能可以完全离线使用，不要求注册账号、登录或连接网络。

## 2. 本应用在本地处理的数据

为了实现功能，本应用可能在设备本地保存：

- 磁贴布局、磁贴显示方式和其他应用设置；
- 展开与收起磁贴的本地使用次数；
- 用户主动创建的配置备份文件；
- 隐私设置和匿名统计同意状态。

这些数据默认保存在设备本地。本应用不会因为读取或保存这些数据而自动上传配置、备份文件、应用列表或自定义磁贴名称。

## 3. 可选的 Microsoft Clarity 匿名统计

本应用集成 Microsoft Clarity，用于在用户明确开启“允许匿名统计”后分析应用使用情况，帮助改进交互体验。该选项默认关闭，不同意不会影响本应用的核心功能。

在用户开启后，Clarity 可能处理以下信息：

- 页面交互行为，例如页面访问和点击行为；
- Android 版本、设备型号等设备基础信息；
- 本应用版本等应用基础信息；
- 本地展开、收起次数对应的统计标签。

本应用会尽量遮挡应用选择器、自定义磁贴名称和跳转目标等敏感界面内容，但无法承诺第三方 SDK 在所有情况下都能达到绝对匿名。Microsoft Clarity 对数据的处理还受其自身隐私政策约束。

用户可以随时在“设置 → 关于”中关闭匿名统计。根据当前 SDK 的能力，关闭后需要重启本应用才能完全停止数据收集。用户也可以通过 Android 系统设置禁止本应用联网。

## 4. 权限与系统数据

本应用可能使用 `WRITE_SECURE_SETTINGS`、Shizuku 和 Android 系统接口来读取或修改系统磁贴配置。相关操作主要在设备本地完成，不会因为授权本身向开发者上传数据。

Shizuku 是独立的第三方软件，其行为受 Shizuku 自身项目说明和许可约束。

## 5. 未来的自动检查更新功能

当前版本尚未实现自动检查更新功能，也不会为了检查更新主动联网。

如果未来增加自动检查更新功能，开发者会在功能启用前更新本隐私政策，说明检查地址、请求时机、发送的数据、联网权限以及关闭方式。未来功能不会改变用户继续离线使用本应用的基本能力。

## 6. 数据保留与删除

本地数据会保留到用户主动修改、删除应用数据或卸载本应用为止。用户可以通过 Android 系统设置清除本应用数据，也可以删除自己导出的备份文件。

由 Microsoft Clarity 处理的数据，其保留和删除规则由 Microsoft 的相关政策决定。

## 7. 政策变更

当功能、数据处理方式或第三方服务发生变化时，本页面会更新生效日期。重大变化会尽量在应用内提供提示。
