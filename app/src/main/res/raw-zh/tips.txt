# exTile 主页「你知道吗？」卡片文案（简体中文）

「使用统计」卡片会显示近 10 天的使用热力图表。
「exTile」的想法最开始来自自动化软件，之后才成为独立应用的。
这是开发者的第一个应用。
「设置」页使用了独特的「手风琴」式菜单。点击展开一个分类会折叠其他分类。
设置中的「磁贴联动」功能是自动化软件很难做到的。exTile 使用了系统 API 做到了这一特色功能。
「创造模式」名字的灵感来自 Minecraft。
如果你有 GitHub 账号的话，给我一个 Star 我会很开心~
如果这个应用对你有用的话，不妨打赏一下呀，谢谢你的使用~
在设置里可以更改长按 exTile 磁贴的行为。开发者推荐选择系统设置~
应用图标的 ± 并不是严格居中的，- 更靠下一些。这是为了视觉平衡。
ex，for EXample，既有 EXpand 的意思，也有 EXtra 的意思，也有 EXcellent 的意思~
应用内置了一些通常状态下见不到的磁贴。
「创造模式」的切层设计灵感来自 QMK / VIA。
在「调试」页可以切换应用语言。
默认的配置模式是「收起/展开」。这是适合大多数人的配置。如果你有更多需求，可以尝试「创造模式」。
